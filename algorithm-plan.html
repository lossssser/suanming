Day 1 · 哈希表建立映射

2 题 · 约 90 分钟
1. 两数之和哈希表 · 补数查询简单

识别信号

需要寻找两个元素满足固定关系，并返回原下标。暴力枚举是 O(n²)，说明可以缓存已经见过的数字。

推导

遍历到 x 时，只需知道 target-x 是否出现过。先查询再写入，可以避免同一个元素被使用两次。

vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> seen;
    for (int i = 0; i < nums.size(); ++i) {
        int need = target - nums[i];
        if (seen.count(need)) return {seen[need], i};
        seen[nums[i]] = i;
    }
    return {};
}

复杂度

平均时间 O(n)，空间 O(n)。哈希表最坏情况可能退化，但面试通常讨论平均复杂度。

易错点

  • 写入后再查询会匹配到自己。
  • 不要排序，排序后原下标会丢失。
  • 说明重复数字如何处理。

49. 字母异位词分组哈希表 · 设计稳定键中等

识别信号

要求把“本质相同、顺序不同”的对象归组，关键不是遍历，而是为同一类对象构造相同的键。

两种键

排序后的字符串简单可靠；26 个字母的频次数组可做到总字符数 O(L)，但要避免拼接歧义。

vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> groups;
    for (const string& s : strs) {
        string key = s;
        sort(key.begin(), key.end());
        groups[key].push_back(s);
    }
    vector<vector<string>> ans;
    for (auto& [_, group] : groups) ans.push_back(move(group));
    return ans;
}

复杂度

设字符串平均长度 k，共 n 个：时间 O(n·k log k)，额外空间 O(nk)。

面试表达

先说明“分组问题要找等价类的规范表示”，再比较排序键与计数键。

Day 2 · 集合与连续区间

1 题 + 重写 Day 1
128. 最长连续序列哈希集合 · 只从区间起点出发中等

核心观察

排序能做但为 O(n log n)。放入集合后，只有 x-1 不存在的 x 才是连续段起点，从起点向右扩展即可。

为什么是 O(n)

虽然有嵌套循环，但每个数最多作为某一连续段成员被访问一次，不是每个起点都重复扫描。

int longestConsecutive(vector<int>& nums) {
    unordered_set<int> values(nums.begin(), nums.end());
    int best = 0;
    for (int x : values) {
        if (values.count(x - 1)) continue;
        int current = x, length = 1;
        while (values.count(current + 1)) {
            ++current;
            ++length;
        }
        best = max(best, length);
    }
    return best;
}

Day 3 · 同向与相向双指针

2 题
283. 移动零同向双指针 · 维护已处理区简单

循环不变量

[0, slow) 始终保存已经遇到的全部非零元素，并保持原相对顺序；fast 负责扫描未知区域。

原地要求

先把非零数压到前面，再把剩余位置补零。这样逻辑比频繁交换更容易证明。

void moveZeroes(vector<int>& nums) {
    int slow = 0;
    for (int x : nums) {
        if (x != 0) nums[slow++] = x;
    }
    while (slow < nums.size()) nums[slow++] = 0;
}

11. 盛最多水的容器相向双指针 · 淘汰不可能更优的一侧中等

移动依据

面积由短板决定。宽度变小已不可避免，移动长板不会提高当前短板，因此只能移动短板寻找更高边界。

证明重点

不是“凭感觉夹逼”。要说明被短板固定的所有更窄组合都不可能超过当前面积，因此可以安全淘汰短板。

int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1, ans = 0;
    while (left < right) {
        ans = max(ans, min(height[left], height[right]) * (right - left));
        if (height[left] < height[right]) ++left;
        else --right;
    }
    return ans;
}

Day 4 · 排序后的双指针

1 题
15. 三数之和排序 + 固定一个数 + 双指针中等

降维

排序后固定 nums[i]，问题变成在右侧有序区间中寻找和为 -nums[i] 的两个数。

去重位置

i 与前一个相同则跳过；找到答案后，left 和 right 都要跨过连续重复值。不要用 set 掩盖去重逻辑。

vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> ans;
    for (int i = 0; i + 2 < nums.size(); ++i) {
        if (nums[i] > 0) break;
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        int left = i + 1, right = nums.size() - 1;
        while (left < right) {
            long long sum = (long long)nums[i] + nums[left] + nums[right];
            if (sum < 0) ++left;
            else if (sum > 0) --right;
            else {
                ans.push_back({nums[i], nums[left], nums[right]});
                int a = nums[left], b = nums[right];
                while (left < right && nums[left] == a) ++left;
                while (left < right && nums[right] == b) --right;
            }
        }
    }
    return ans;
}

Day 5 · 滑动窗口

2 题
3. 无重复字符的最长子串可变窗口 · 维护无重复条件中等

窗口定义

[left, right] 始终是不含重复字符的合法窗口。right 扩张；若字符重复，left 直接跳到该字符上次位置之后。

关键保护

left 只能向右移动，所以更新时使用 max(left, last[c] + 1)，防止被窗口外的旧位置拉回去。

int lengthOfLongestSubstring(string s) {
    vector<int> last(256, -1);
    int left = 0, best = 0;
    for (int right = 0; right < s.size(); ++right) {
        left = max(left, last[(unsigned char)s[right]] + 1);
        last[(unsigned char)s[right]] = right;
        best = max(best, right - left + 1);
    }
    return best;
}

438. 找到字符串中所有字母异位词定长窗口 · 频次差中等

窗口长度

异位词长度必然等于 p，因此窗口固定为 p.size()。每次右侧加入一个字符，超长后左侧移出一个字符。

状态选择

初学可直接比较两个 26 长数组，复杂度仍是 O(26n)。熟练后可维护不匹配字符种类数。

vector<int> findAnagrams(string s, string p) {
    if (p.size() > s.size()) return {};
    array<int, 26> need{}, window{};
    for (char c : p) ++need[c - 'a'];
    vector<int> ans;
    for (int right = 0; right < s.size(); ++right) {
        ++window[s[right] - 'a'];
        if (right >= p.size()) --window[s[right - p.size()] - 'a'];
        if (right + 1 >= p.size() && window == need)
            ans.push_back(right - p.size() + 1);
    }
    return ans;
}

Day 6 · 综合与周测

2 题 · 限时训练
42. 接雨水相向双指针 · 维护左右最高墙困难

本质

位置 i 的水量是 min(左侧最高, 右侧最高)-height[i]。双指针用于在不知道另一侧精确最高值时，先结算较矮侧。

结算条件

当 leftMax ≤ rightMax，左侧当前位置的上界已经由 leftMax 决定，右侧至少存在 rightMax 兜底，可安全结算。

int trap(vector<int>& height) {
    int left = 0, right = height.size() - 1;
    int leftMax = 0, rightMax = 0, water = 0;
    while (left <= right) {
        if (leftMax <= rightMax) {
            leftMax = max(leftMax, height[left]);
            water += leftMax - height[left++];
        } else {
            rightMax = max(rightMax, height[right]);
            water += rightMax - height[right--];
        }
    }
    return water;
}
